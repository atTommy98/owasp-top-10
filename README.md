# OWASP Top 10 Practice Project

## Description

This OWASP playground intends to improve my understanding of common security flaws in software applications, starting
with the most critical and common. All code has been handwritten, but AI was used to explain the issues in a
comprehensive manner and point me in the right direction. I started this project to fill gaps in my knowledge and
improve my back-end skills in general. Also, it's fun breaking things!

## Processes

My thought processes and actions taken are all written in the `/docs` folder, where each file addresses one of the top 10
OWASP entries from 2025 along with some further detail behind each.

## What is OWASP?

The Open Worldwide Application Security Project (OWASP) is an open community dedicated to helping organisations and
individuals develop, purchase and maintain applications and APIs that can be trusted. The OWASP project provides a
plethora of tools and information such as:

- Application security tools and standards to adhere to.
- Cutting edge security research
- Software security protocols and libraries
- Books, presentations, videos and cheat sheets on many common topics and security testing, code development and secure
  code reviews31
